Probabilistic ML: Reinforcement Learning

35.1 Introduction

RL의 개념: “경험으로 학습한다” — 상태에 따라 더 많은 보상을 받을 수 있는 행동을 agent가 할 수 있도록 policy를 만들도록 하는 학습. 라벨 필요 없음.

강화학습의 구성 요소: 환경(Environment), 에이전트(Agent), 행동(Action), 보상(Reward)

Discounted cumulative reward:

\[G_0 \triangleq \sum_{t=0}^{T-1} \gamma^t r_t\]
  • \(\gamma = 1\): 미래 보상을 전혀 할인하지 않음
  • \(\gamma = 0\): 현재 보상만 고려
  • \(0 < \gamma < 1\): 시간이 지날수록 미래 보상이 점점 더 작게 반영됨

Value functions:

\[V^*(s) = \max_a \left[R(s, a) + \gamma\, \mathbb{E}_{p(s' \mid s,a)}[V^*(s')]\right]\] \[Q^*(s, a) = R(s, a) + \gamma\, \mathbb{E}_{p(s' \mid s,a)}\left[\max_{a'} Q^*(s', a')\right]\] \[V^*(s) = \max_a Q^*(s, a), \quad \pi^*(s) = \arg\max_a Q^*(s, a)\]

RL 방법의 분류

기준 방법
에이전트가 학습하는 대상 가치 함수 / 정책 / 모델
행동 선택 방식 On-policy / Off-policy
모델 사용 여부 Model-free / Model-based
학습 대상 Value-based / Policy-based

35.1.5 Exploration–Exploitation Tradeoff

  • Exploitation(이용): 지금까지 경험으로 보상이 높다고 아는 행동 선택 → 당장 이득 큼
  • Exploration(탐험): 아직 보상이 확실치 않은 행동도 시도 → 더 나은 장기 보상 발견 가능성

\(\varepsilon\)-greedy:

\[a_t = \begin{cases} \arg\max_a \hat{R}(s_t, a) & \text{probability } 1 - \varepsilon \\ \text{random action} & \text{probability } \varepsilon \end{cases}\]

랜덤 탐험할 때 좋은 행동과 나쁜 행동을 구분하지 않고 균등 확률로 선택 → 비효율적.

Boltzmann exploration:

\[\pi(a \mid s) = \frac{\exp(\hat{R}(s, a) / \tau)}{\sum_{a'} \exp(\hat{R}(s, a') / \tau)}\]

\(\tau \to 0\): greedy 정책, \(\tau \to \infty\): 균등 정책.

UCB (Upper Confidence Bounds):

\[\hat{r} = r + \rho\sqrt{\frac{1}{N_{s,a}}}\]

자주 안해본 행동(N 작으면)이라면 exploration bonus가 커져서 더 선택하게 만든다.

35.2 Value-based RL

35.2.1 Monte Carlo RL

Q 함수를 추정하는 가장 간단한 방법: action → 나머지 궤적을 정책 \(\pi\)에 따라 샘플링 → discounted reward 합 평균.

Policy iteration과 함께 사용:

\[\pi_{k+1} = \arg\max_a Q_k(s, a)\]

단점: 많은 궤적을 unroll해야 하기 때문에 분산이 매우 큼. episodic tasks로 제한.

35.2.2 Temporal Difference (TD) Learning

MC RL보다 더 효율적: 궤적 전체가 아니라 샘플된 state의 Bellman 오차를 점차 줄여나가는 방식.

\[V(s_t) \leftarrow V(s_t) + \eta\left[r_t + \gamma V(s_{t+1}) - V(s_t)\right]\]

TD error: \(r_t + \gamma V(s_{t+1}) - V(s_t)\) (Bootstrapping target 이용)

35.2.3 TD with Eligibility Traces (TD(\(\lambda\)))

MC와 TD 사이를 interpolate:

\[G_t^\lambda \triangleq (1 - \lambda) \sum_{n=1}^{\infty} \lambda^{n-1} G_{t:t+n}\]

\(\lambda \in [0, 1]\): convex combination of n-step return 보장. eligibility traces를 이용하면 efficient하게 계산 가능.

35.2.4 SARSA: On-policy TD Control

\[Q(s, a) \leftarrow Q(s, a) + \eta[r + \lambda Q(s', a') - Q(s, a)], \quad a' \sim \pi(s')\]

Q가 업데이트되면 \(\pi\)는 Q에 대해 greedy하게 정의되어 있으므로 같이 update. GLIE policy 적용 시 optimal \(Q^*\)와 \(\pi^*\)로 수렴 보장.

35.6 Control as Inference

Policy optimization에 대한 확률적 추론 접근.

35.6.1 Maximum Entropy Reinforcement Learning

새로운 변수 \(o_t\) 도입 (t의 행동이 최적인지 아닌지를 나타내는 이진 변수):

\[p(o_t = 1 \mid s_t, a_t) = \exp(\lambda^{-1} R(s_t, a_t))\]

trajectory likelihood:

\[p(\tau \mid o_{0:T-1} = 1) \propto \exp\!\left(\lambda^{-1} \sum_{t=0}^{T-1} R(s_t, a_t)\right)\]

KL divergence 최소화로 정책 \(\pi_\theta(a_t \mid s_t) \approx p(a_t \mid s_t, o_{t:T-1} = 1)\) 근사:

\[D_\text{KL}(p_\theta(\tau) \| p(\tau \mid o = 1)) = -\mathbb{E}_{p_\theta}\!\left[\lambda^{-1} \sum R(s_t, a_t) + \mathcal{H}(\pi_\theta(s_t))\right] + \text{const}\]

여기서 \(\mathcal{H}(\pi_\theta(s)) = -\sum_a \pi_\theta(a \mid s) \log \pi_\theta(a \mid s)\) (정책의 엔트로피).

이를 Maximum Entropy RL (MERL) 이라 부름 — Q함수에 entropy 관련 항을 추가하는 것이 key point:

\[Q^*(s_t, a_t) = \lambda^{-1} R(s_t, a_t) + \mathbb{E}_{p(s_{t+1} \mid s_t, a_t)}\!\left[\log \int_A \exp(Q^*(s_{t+1}, a_{t+1}))\, da\right]\]

35.6.2 VIREL (Variational Inference for RL)

Maximum Entropy RL의 대안 모델:

\[p(o_t = 1 \mid s_t, a_t) = \exp\!\left(\lambda_w^{-1}\left(Q_w(s_t, a_t) - \max_a Q_w(s_t, a)\right)\right)\]

Objective function:

\[J(\theta) = \mathbb{E}_{\pi_\theta}[Q_w(s, a) + \lambda\, \mathcal{H}(\pi(\cdot \mid s))]\]

EM으로 학습:

  • E step (policy improvement): critic parameter \(w\) 고정, actor parameter \(\theta\) 업데이트 \(\theta \leftarrow \theta + \eta_\theta \nabla_\theta L(w, \theta)\)
  • M step (policy evaluation): actor parameter \(\theta\) 고정, critic parameter \(w\) 업데이트 \(w \leftarrow w + \eta_w \nabla_w L(w, \theta)\)

Active Inference: 뇌과학의 free energy principle 기반. state estimation(perception)과 parameter estimation(learning)을 동시에 추정 (variational Bayes EM과 같은 구조).
