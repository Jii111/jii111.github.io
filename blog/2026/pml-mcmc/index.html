Probabilistic ML: MCMC

2026   ·   machine-learning   probabilistic-ml   MCMC   bayesian   sampling   ·   study_notes

12.1 Introduction

MCMC (Markov Chain Monte Carlo): 고차원 분포로부터의 샘플링에 널리 사용되는 방법.

  • Markov Chain: 어떤 상태에서 다른 상태로 넘어갈 때, 바로 전 단계의 상태에만 영향을 받는 확률 과정
  • Monte Carlo: 해석적으로 구하기 어려운 함수 값을 샘플링을 통해 ‘근사적’으로 구하고자 하는 방법론

Basic idea: state space 상에서 Markov Chain을 구성하는 것.

  • Markov chain의 stationary distribution이 target 확률 밀도 함수 \(p^*(x)\)
  • state space에서 random walk 수행 → 각 state에 머무는 시간의 비율은 \(p^*(x)\)에 비례

전반적인 과정:

  1. 목표: 타겟 분포 \(p(x)\)를 따르는 샘플 추출
  2. random initialization
  3. 제안 분포 \(q(x)\)를 이용해서 샘플 \(x_{s+1}\) 제안
  4. acceptance probability 이용해 accept or reject 과정 무수히 반복

12.2 Metropolis-Hastings (MH) Algorithm

기본 아이디어

각 단계에서 current state \(x\)에서 new state \(x'\)으로의 이동을 확률 \(q(x' \mid x)\)로 제안.

\(q\): proposal distribution — 어떤 종류든 사용 가능 → MH algorithm은 매우 유연.

1) Symmetric proposal (\(q(x' \mid x) = q(x \mid x')\)):

\[A = \min\!\left(1,\; \frac{p^*(x')}{p^*(x)}\right)\]

\(p^*(x') > p^*(x)\)이면 무조건 이동. \(p^*(x') < p^*(x)\)여도 확률 비율에 따라 이동할 수 있음.

2) Asymmetric proposal: Hastings 보정 필요

\[\alpha = \frac{p^*(x')\, q(x \mid x')}{p^*(x)\, q(x' \mid x)}, \quad A = \min(1, \alpha)\]

acceptance probability를 계산할 때, 정규화되지 않은 확률 밀도만 알면 되므로 Z 몰라도 A 계산 가능.

Why MH Works

MH 알고리즘은 detailed balance 만족:

\[p(x' \mid x)\, p^*(x) = p(x \mid x')\, p^*(x')\]

detailed balance를 만족하면 그 체인의 stationary distribution은 \(p^*\).

12.2.3 Proposal Distributions

Independence sampler: \(q(x') = q(x')\) (x와 독립)

Random Walk Metropolis (RWM):

\[q(x' \mid x) = \mathcal{N}(x' \mid x, \tau^2 I)\]

분산 \(\tau^2\)를 잘 조절하는 게 핵심.

Composing proposals:

\[q(x' \mid x) = \sum_{k=1}^{K} w_k\, q_k(x' \mid x)\]

각 제안 분포가 detailed balance를 만족하면 mixture \(q(x' \mid x)\)도 만족.

Adaptive MCMC: 알고리즘 실행 도중에 proposal의 파라미터를 조정해서 효율을 높이는 방식.

12.4 Auxiliary Variable MCMC

변수들 간의 상관 관계를 줄이기 위해 보조 변수 도입.

12.4.1 Slice Sampling

샘플링하고 싶은 분포: univariate but multimodal distribution \(p(x) = \tilde{p}(x) / Z_p\).

\(\tilde{p}(x)\)를 몰라서 샘플링 어려움 → adding a uniform auxiliary variable!

Joint distribution:

\[\hat{p}(x, v) = \begin{cases} \frac{1}{Z_p} & \text{if } 0 \le v \le \tilde{p}(x) \\ 0 & \text{otherwise} \end{cases}\]

Marginal distribution over x = \(p(x)\) → \(v\)를 버리면 \(x \sim p(x)\) 샘플 보장.

Step 1: \(x_i\)가 주어졌을 때 \(v_{i+1} \sim U[0, \tilde{p}(x_i)]\) 샘플링

Step 2: construct slice \(A_{i+1} = \{x : \tilde{p}(x) \ge v_{i+1}\}\) — stepping out 반복

Step 3: \(x_{i+1}\)을 이 영역에서 uniformly 샘플링

12.6 MCMC Convergence

Burn-in phase: 초기 상태의 영향을 강하게 받아 버려야 하는 initial period.

Mixing time: stationary distribution으로 수렴하는데까지 걸리는 시간.

12.6.1 Mixing Rates

\[\tau_\epsilon(x_0) = \min\!\left\{t : \left\|\delta_{x_0} T^t - p^*\right\|_1 \le \epsilon\right\}\]

Mixing time은 eigen gap \(\gamma = \lambda_1 - \lambda_2\)에 의해 결정됨.

체인이 \(x_1, x_2, x_3\) 중 한 곳에서 시작하면 그 내부를 빠르게 탐색하지만, \(x_4 \sim x_7\)로 넘어가는데는 매우 오래 걸림 → 병목 현상.

12.6.2 Practical Convergence Diagnostics

Trace plots: 여러 개의 체인(보통 3-4개)을 서로 다른 시작점에서 시작해서 돌리고 관심 있는 값을 시간에 따라 그려봄.

  • 수렴했다면: 서로 다른 체인들이 비슷한 구간을 움직이며 overlap하는 형태
  • Trace rank plot: 각 체인의 샘플이 전체 샘플들 중에서 어느 순위(rank)에 있는지 표현 → 수렴했다면 distribution over ranks should be uniform

EPSR (Estimated Potential Scale Reduction):

Within-chain variance: \(W = \frac{1}{M} \sum_{m=1}^{M} s_m^2\)

Between-chain variance: \(B = \frac{N}{M-1} \sum_{m=1}^{M} (\bar{x}_m - \bar{x}_\cdot)^2\)

\[\hat{R} = \sqrt{\frac{V}{W}}, \quad V = \left(1 - \frac{1}{N}\right)W + \frac{1}{N}B\]

\(\hat{R}\)이 1에 가까우면 수렴했다고 판단.

12.6.3 Effective Sample Size

MCMC 샘플은 일반적으로 서로 correlated → 실제 독립 샘플로 몇 개와 같은지 확인.

\[\text{Var}[\bar{x}] = \frac{\sigma^2}{N}\rho, \quad \rho = 1 + 2\sum_{\ell=1}^{\infty} \rho(\ell)\] \[N_{\text{eff}} \triangleq \frac{N}{\rho} = \frac{N}{1 + 2\sum_{\ell=1}^{\infty} \rho(\ell)}\]

correlation이 클수록 효과적인 샘플 수 줄어든다.

Good/worse cases:

  • (a) 제안 분포의 분산이 작아서 샘플이 조금씩 움직임 → 자기상관 큼
  • (b) 제안 분포의 분산이 커서 대부분 제안 거절 → 자기상관 큼
  • (c) 적당한 분산 → 빠르게 자기상관 줄어듦
  • (d) 각 변수의 조건부 분포로 직접 샘플링 → 빠르게 자기상관 줄어듦

12.9 Annealing Methods

실제 다루는 많은 분포들은 multimodal → local mode에 갇혀버릴 수 있음.

아이디어: 분포를 부드럽게 만들고, 점점 기존의 울퉁불퉁한 분포로 돌아오는 방식.

12.9.1 Simulated Annealing

\[p_T(x) = \exp(-E(x)/T)\]
  • High temperature \(T \gg 1\): 전체가 평평해짐 → 모든 위치에서 자유롭게 이동 가능 (local minima 탈출 쉬움)
  • Low temperature \(T \ll 1\): 큰 피크는 더 커지고 작은 피크는 사라짐 → global optimum으로 수렴

Acceptance probability:

\[\alpha_{t+1} = \exp(-(E(x') - E(x_t)) / T_t)\]

Exponential cooling schedule:

\[T_{t+1} = \gamma T_t, \quad \gamma \in (0, 1]\]

너무 빠르면 local optimum에 갇힐 수 있고, 너무 느리면 시간이 많이 소요됨.

12.9.2 Parallel Tempering

서로 다른 온도를 갖는 여러 개의 체인을 병렬로 돌리는 것. 온도가 비슷한 체인끼리 샘플을 교환.

state space를 멀리까지 탐색하는 높은 온도의 체인이 낮은 온도의 체인에게도 영향을 줌.
