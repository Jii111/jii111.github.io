Developed a Korean query-response framework optimized for cost efficiency and domain adaptation in real-world service environments

- Project Overview
• AI SEOUL Fellowship Project in collaboration with Docenty
• Designed an FAQ-driven DST method that retrieves domain-relevant examples and reduces redundant LLM calls through FAQ-based utterance grouping
• Fine-tuned a Korean-adapted Ko-RefPyDST retriever, achieving a +1.9 accuracy gain over fully trained DST models while using only 10% of the training data

- Pipeline Design for LLM Efficiency
• Improved my ability to design efficient LLM pipelines for query handling. 
• Addressed practical challenges commonly encountered in real-world service environments.
