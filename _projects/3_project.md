Predicted loan applications and segmented users with data from a financial app

- Project Overview
• Utilized user demographic data and in-app behavioral log data for a financial application, engineering features and external variables
• ① Loan Application Prediction: Implemented an ensemble of five models—including Random Forest, XGBoost, and Elliptic—to forecast loan application behavior.
• ② Customer Segmentation: Applied a GMM-based clustering model to classify users into four distinct behavioral segments

- Scalable Data Analysis : Enhanced my capability to work with high-volume behavioral log data through preprocessing, feature engineering, and modeling

- Applied Machine Learning
• Engineered meaningful features from raw data, integrated external variables, and tested multiple algorithms—including ensemble approaches—to develop more reliable prediction models.
• Performed model diagnostics such as feature importance to refine model behavior and ensure stable performance
